# Globe Data Viz

3D-визуализация мировых данных (население, ВВП) с использованием Three.js


## Особенности
- Интерактивный 3D-глобус с визуализацией данных по странам
- Несколько типов данных: население, ВВП, ВВП на душу населения
- Переключение данных в реальном времени
- Интерактивная информация при наведении курсора
- Управление камерой

## Технологический стек
- **Three.js** - 3D-графика
- **JavaScript (ES6+)** - основная логика
- **HTML5/CSS3** - пользовательский интерфейс
- **Git/GitHub** - система контроля версий

## Структура проекта
globe-data-viz/
├── data/ # Данные по странам (JSON)
├── src/ # Исходный код
│ └── main.js # Основная логика приложения
├── index.html # Основной HTML-файл
├── README.md # Документация проекта

## Использование
-Откройте приложение

-Используйте мышь для вращения/масштабирования глобуса

-Определите страну, которую хотите посмотреть

-Наведите курсор на столбцы, чтобы увидеть подробную информацию о стране
